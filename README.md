# Punjkora Public School Balambat - School Management System

Single-file school management web app (Roman Urdu / English / Urdu certificates).

## Features
Students (photo, DOB, Excel/PDF import) | Attendance + WhatsApp | Fees tracker + Receipts |
Subjects per class | Results + DMC (2 per A4) | Certificates (English/Urdu) |
Teachers | Timetable (master, class-wise, teacher-wise, PDF) | Notices | Backup

## GitHub Pages par chalane ka tareeqa
1. GitHub par naya repository banayein (e.g. `pps-school`).
2. `index.html` aur `README.md` upload karein (Add file -> Upload files).
3. Settings -> Pages -> Source: `Deploy from a branch` -> Branch: `main` / `(root)` -> Save.
4. 1-2 minute baad link: `https://<username>.github.io/pps-school/`

## Zaroori
- Data browser ki localStorage mein save hota hai (har device/browser ka alag). Backup tab se waqfe waqfe backup lein.
- Excel/PDF import ke liye internet chahiye (cdnjs se library load hoti hai).
